# MV Music Analyzer v0.8.4 — 改稿案の作成・判断・書き出し

v0.8.3改稿用JSONから、未改変の元CUTと独立した編集用CUTを作ります。解析イベントの変化は根拠として表示するだけで、コンテや動作の時刻に自動適用しません。採用判断でも元コンテを上書きしません。

## スマホでの操作

1. 「改稿案作成」でv0.8.3改稿用JSONを読み込むか、「画面の改稿用JSONを使用」を押します。解析JSONの再選択は不要です。
2. CUTを選び、「元コンテ」と「解析イベントの変更根拠」を確認します。
3. 「改稿案を編集」の各項目を編集します。時刻は数値欄、構図・被写体・動作・カメラ等の文字列は個別の入力欄です。元データの階層・配列は保持します。長いJSONを直接編集する必要はありません。識別IDと参照情報は読み取り専用です。
4. 元コンテとの編集差分を確認し、「未判断／元コンテを維持／改稿案を採用／再検討」を選び、改稿内容・理由・未確認事項を記入します。元データにない演出の補足は「改稿内容・補足」に作者自身が記入できます。
5. 前後CUTや衣装等を確認します。任意の元コンテを上の「コンテJSON」に読み込んである場合は「読み込み済み元コンテで前後情報を更新」で利用できます。この操作では確認状態を未確認へ戻しますが、改稿案や確認メモを消しません。
6. 「改稿案JSONを書き出す」で保存します。画面内の編集はページ更新で失われるため、更新前に書き出してください。別の改稿用JSONへの切り替えには未保存編集を破棄する確認を表示します。

0件の改稿用JSONは「改稿対象なし」と表示し、空配列の改稿案JSONを書き出せます。改稿案JSON自体を再インポートする機能や元コンテへの反映は今回の対象外です。

## 出力形式

ファイル名：`mv_storyboard_revision_proposal_v0_8_4.json`

- `schema`: `mv_storyboard_revision_proposal.v0.8.4`
- `version`: `0.8.4`
- `source_handoff`: 元のschema/version/id、内容フィンガープリント、元レビューと元コンテの識別情報。存在しないIDはnullです。フィンガープリントは既存stableId方式で、暗号学的同一性保証ではありません。
- `baseline_saved_at`: 元の比較基準保存日時。
- `target_count` / `targets[]`: 入力対象だけを保持します。
- 各対象の `cut_id` / `cut_number`: 元の参照情報。
- `original_cut`: 入力にある元CUTの未改変コピー。
- `draft_cut`: 独立した編集用コピー。最初は元CUTと同じ値です。
- `draft_changes`: 元CUTと編集用CUTの差分。path配列と変更前後の値。
- `review_entries`: 元のレビュー判断、変更イベントID、解析の前後値・移動量等を丸ごと保持。
- `decision`: `unreviewed` / `keep_original` / `adopt_proposal` / `reconsider`。
- `revision_summary` / `reason` / `unconfirmed_notes`: 作者による改稿内容・理由・未確認事項。
- `continuity`: 前後CUTの取得根拠と元データ、境界時刻の確認情報、作者の項目別確認状態・メモ。

元コンテ維持を選んでも編集途中のdraft_cutを削除せず保持します。採用しても元コンテへ反映しません。どちらの判断でもoriginal_cutは不変です。

## 前後CUTの扱い

元CUTの `previous_cut_id` / `next_cut_id` または `connections` 内の同名IDを優先します。接続先は読み込まれた元コンテから同じIDだけを探します。明示IDがない場合は、元コンテ内で対象IDを一意に特定できた場合に限り配列順の前後を提示し、演出上の接続とは断定しません。

入力の改稿用JSONには通常、非対象の前後CUTが含まれません。その場合は未取得・未確認です。人数、小道具、衣装、動作、カメラの意味的な整合は自動判定せず、作者が「未確認／整合を確認／不整合」を選びます。元にない情報を補いません。

境界時刻だけは数値で比較します。一致は「境界時刻のみ一致」、空白や重複は意図確認、開始・終了の逆転や負値は不整合として表示します。動作まで整合しているとは判定しません。数値時刻が取得できない場合は未確認です。改稿案の値を編集すると、作者の確認状態を未確認へ戻します。

## 保護・検証

解析、211参照比較、影響CUT判定、メタデータ指摘の分離、比較基準の保存・旧形式互換は変更していません。この機能は保存済み比較基準へ書き込みません。入力のコンテ・解析・レビュー・改稿用JSONも変更しません。

回帰A〜Fと、元データ不変、合成の右ヒール動作時刻の非自動変更、時刻境界と作者判断の区別、JSON往復を確認します。ブラウザでは入力・編集・判断・理由・書き出し・対象0件・幅320/390pxを確認します。実44CUT・スマートフォン実機は未検証です。右ヒールを含むテストは明示的な合成データであり、実コンテの再現を主張しません。
